# 矛盾判定规则（G3，永远人审，不自动应用）

三步，顺序不能反：
1. **同场景**：两条讨论的是同一类对象、同一价格带/同一层级/同一阶段？不是 → `different_scene`，停。
2. **同决策维度**：两条回答的是同一个"该怎么定"的问题？不是 → 停。
3. **方向相反**：给出的建议方向相反？相反 → `contradicts`；同向补充 → `same_direction`（多半是 refines 或近似重复）。

标注时写清各自成立的条件；矛盾的价值不是判谁对，是让使用者先判断自己落在哪个条件下。

## "同场景"在本领域怎么定义
{客户领域填：例如代码库里"同一事件总线上的两个消费者"，运营手册里"同一客群同一价格带"。}
