# 风物执守（XY 操盘系统）· 功能说明书

一句话：**这是一套装进 AI 里的商业与私域操盘系统。** 你把生意的实情告诉它，它按 27,966 条实战原子（77 节私域课 + 真实账号运营 + 一线操盘案例 + 四大平台现行规则 + 企业AI落地方法论）帮你诊断、拆解、推进——私域是主体，短视频/流量/AI 是私域自带的能力。

46 个 skill + 1 个教练，按你生意推进的顺序排：

## 0 · 入口（不知道用哪个，从这里进）
| skill | 干什么 |
|---|---|
| **/xy** | 总入口。新手教程、帮你挑对的 skill、做完一件事告诉你下一件 |
| **xy-coach** | 操盘教练。首次见面 5 问或 10 格生意档案表建档，之后记得你的盘子，每次只推进一步，句句带原子证据 |
