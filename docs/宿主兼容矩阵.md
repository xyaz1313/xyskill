## 大脑链路（三选一，用户在 `~/.xy/config.json` 里定，默认 host）
```
用户 ──对话──> 宿主 Agent（Claude Code / Codex / WorkBuddy / 豆包 / Kimi …）
                 │ 读 skills/agents（我们的包）
                 ▼
          xy-coach（agent 或 SKILL 形态）
                 ├─ brain=host      → 直接用宿主模型思考（默认，零配置）
                 └─ brain=external  → scripts/xy-brain 调第三方 API（DeepSeek/通义/Kimi/Claude…，OpenAI 兼容或 Anthropic）
                                       宿主只负责对话与文件读写；API 失败退回 host
                 │
                 ├─ 知识：scripts/atoms-search.py → knowledge/atoms.jsonl（或各 skill references/atoms/）
                 ├─ 流程：/xy 路由 → 调用 xy-* skill
                 └─ 记忆：~/.xy/{profile.md, sessions/, decisions/, config.json}（宿主无关）
```
- 密钥只从环境变量读（`api_key_env`），不落盘明文。
- 三档宿主也能"有教练"：Skill 版 + 外挂脑 = 功能上接近完整版，只少了 subagent 的并行与 hook 首启。

## 每宿主必过的烟雾测试（写进 CI 或手工清单）
安装 → 首启（无档案 → 访谈 → 写 profile）→ 说一个真实处境 → 正确路由到 xy-* → 回答里含 ≥3 个原子 id → 收口三行 → `~/.xy/profile.md` 有追加。任何一环失败即该宿主标"未支持"，不能宣称兼容。
